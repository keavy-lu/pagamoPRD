**必要：**&#x4E00;般電競賽、特殊地圖電競賽

**非必要 (ToB、K12 表示目前沒需要)：**&#x73ED;級競賽之盾、官方競賽之盾、奪寶信號。（此三類有獎勵需帶回原課程，且結算與電競結算不同）

## 功能(Key Features)&#x20;

1. 電競後台賽後設定改版：後端/前端
2. App補跳轉功能：後端/App
3. 勝敗訊息與跳轉功能解綁脫鉤：後端/前端/App
4. 新排名底層架構：後端
5. 賽後設定＋新排名：前端
6. 世界設定-排行榜設定＋新排名：前端
7. 報名者管理 - 戰積頁＋新排名：前端
8. 新版電競結算介面：後端/前端/App
9. 支援顯示新排名：後端、前端、App
   * 電競即時排名
   * 頭像內戰績排名

## 用戶流程(User Flow)

1. 管理者：
   1. 可在世界設定頁開啟新排名
   2. 可經由電競後台賽後設定控制出現新排名
   3. 正式比賽時，可在報名者管理戰績頁看到新排名
   4. 正式比賽時，可在即時排行切換看到新排名
   5. 正式比賽時，可在頭像內戰績排名看到新排名
   6. 結算時可以看到新排名
2. 參賽者：
   1. 正式比賽時，可在報名者管理戰績頁看到新排名
   2. 正式比賽時，可在即時排行切換看到新排名
   3. 正式比賽時，可在頭像內戰績排名看到新排名
   4. 結算時可以看到新排名

## 重要邏輯(Key Logics)&#x20;

1. 顯示其他排行榜
   1. &#x20;\[ 開/關 ] 個人排名前＿名
      1.  若開啟，數字欄位預設為1，且無法設定小於 1 。開啟時結算畫面會顯示其他排行榜區塊。
      2. 若關閉，不會顯示此排名
   2. &#x20;\[ 開/關 ] 國家內排名前＿名 
      1. 同一個國家的人，以個人積分作為排名。 
      2. 若開啟，數字欄位預設為1，且無法設定小於 1 。開啟時結算畫面會顯示其他排行榜區塊。 
      3. 以該賽場所有參賽者選填的國家分群，在遊戲端裡的結算介面，將分別顯示各國家內的人積分排名。
