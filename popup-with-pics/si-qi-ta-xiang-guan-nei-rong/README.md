## 會議紀錄&#x20;

討論問題：

* 後端發現彈窗的文案，是隨著翻譯檔一起傳給前台，所以當用戶會自己看 API 內容時，就可以在「還沒取得該道具的情況下，先知道使用該道具後會看到的內容」
  * 這是目前的機制，先同步給 PM，評估要不要優先排工項解決掉（例如改成擁有該道具的人才能拿到使用後的文案）
* 因爲支援 HTML ，所以可能性很多，建議先討論目前會用到的格式就好
  * 然後是提供文字/圖片給做道具的後端產出 HTML，不要由需求端直接提供 HTML

以上資訊先同步，詳細可以預排會議一起討論延伸補充資料&#x20;
