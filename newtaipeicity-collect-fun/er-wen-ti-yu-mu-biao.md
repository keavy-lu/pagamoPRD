# 二、問題與目標

## 1. 目標用戶(Target User)&#x20;

1. 新北市玩家（學生）&#x20;
2. 新北親師生平台、教育局&#x20;

## 2. 主要問題定義&#x20;

1. 持續推進 PaGamO 新北學生用戶的高使用率、高活耀度和高遊戲使用時長&#x20;
2. 加入新北親師生平台積點趣，在與其他新北合作教育平台競爭中，保持領先地位&#x20;

## 3. 解決方向（High level Approach）

1. 在遊戲裡進行某些行為，可以化為新北的點數（用來兌換新北獎勵）&#x20;
2. 與新北縣市合作，以積點趣機制鼓勵用戶提升使用率和活躍度&#x20;

## 4. 目標與衡量指標&#x20;

1. 目標 \
   引導新北用戶&#x20;
   1. 領取每日獎勵&#x20;
   2. 訓練土地（答題）&#x20;
   3. 消耗能量後使用能量道具（答題）&#x20;
   4. 送好友能量&#x20;
2. 非本次目標&#x20;
   1. 非新北帳號不是本次目標&#x20;
   2. 不能提升活耀度、不能提高使用率的活動不會是積點行為
   3. 對流量或系統負擔過重的遊戲行為不是選項&#x20;
   4. 不針對新北專屬課程（不分專屬/公開課程）&#x20;
3. 成功的衡量方式&#x20;
   1. PaGamO 新北學生的使用率提升（新北用戶 PaGamO 遊戲上線次數提升）&#x20;
   2. PaGamO 新北學生的活躍度提升（日/週/月活躍用戶增加）&#x20;
   3. PaGamO 新北學生的平均答題次數增加（日/週/月平均答題次數增加）（包含自選、非素養任務，此項要和da討論）
