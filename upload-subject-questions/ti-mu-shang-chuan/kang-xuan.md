# 康軒

* OP 複製舊學年題庫，例如：複製冊次"三上113"內所有題目到新的冊次“三上114”
* 根據康軒提供的章節資料修正現有題庫的章節，包含
  1. 章節改名
  2. 章節刪除
  3. 章節調整順序
  4. 修改題目
  5. 上傳題目（將題目貼到批量上傳 Excel，使用批量上傳功能上傳）
     1. 科目、冊次、章節 填寫題庫既存的名稱
     2. 若南一翰林有相似的單元，可以將題目也上傳到南一翰林的單元
* 章節改名、刪除完畢，就可以請 RD 將冊次學年度改為「0」 OP：
