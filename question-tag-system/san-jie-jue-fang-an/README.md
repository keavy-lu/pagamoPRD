# 三、解決方案

## 功能(Key Features)&#x20;

條列和此次解決方案範圍有關的功能，盡可能依照優先順序排序，確定與解決方案有關的功能邊界，避免過度發散而失焦，較大的功能，細節請撰寫到產品規格文件

1. 管理者後台>產品管理>教學資源，新增「題目標籤與類別管理」
   1. 標籤類別新增：透過 OP，根據使用需求和情境新增類別
      1. 例如：領域、程度、素養能力、教育部議題、SDGS、課綱能力指標、學力檢測等
      2. 類別可能有特定用途，例如：素養能力的標籤會用在雷達圖數據資料，可挑選出特定指標綁定商品
   2. 標籤類別使用權限：設定該類別可使用的課程世界
      1. 具有使用權限的課程世界的課程題庫才會顯示該類別供使用者選擇（或不區分權限）
      2. 個人題庫暫時先都不開放
   3. 在類別之下可以自行新增、修改標籤，例如：
      1. <mark style="color:yellow;">\[類別]領域>\[標籤]國語文、英語文、數學、自然</mark>
      2. <mark style="color:yellow;">\[類別]程度>\[標籤]一年級、二年級、三年級</mark>
      3. <mark style="color:yellow;">\[類別]素養能力>\[標籤]統整解釋、擷取訊息、知識、理解、應用</mark>
      4. <mark style="color:yellow;">\[類別]課綱能力指標>\[標籤]（量太大，主要會透過題目上傳時設定）連結</mark>
      5. \[類別]教育部議題>\[標籤]性別平等、環境、人權
2. 題庫管理後台>題目分類設定，新增「題目標籤類別」設定
   1. 標籤類別，使用者可自行決定要設定哪些類別下的標籤
      1. 基本項目：領域、程度
      2. 自行新增：避免列出過多選項，使用者可從選單中選擇要設定的類別
   2. 其它標籤：
      1. 可直接輸入，會自動在題庫新增標籤，設定其他題目時也會自動在輸入欄位下方出現建議
      2. 輸入其它標籤時，有選擇領域、程度，當其他使用者選擇相同的領域或程度時，會出現這個標籤讓其他使用者選擇
      3. 輸入其它標籤時，沒有選擇領域、程度，則該標籤只有該題庫的使用者能看到
   3. 標籤可以多選
3. 題庫管理後台>題目列表篩選器
   1. 根據所選題庫，撈取所有題目有使用到的標籤，顯示標籤類別



題目設定的範例：

* 標籤類別/標籤：學習主題/字母、語音、字詞、句構 （同時選擇英語文、二年級），其他使用者在選擇「英語文」或「二年級」時，會出現這些標籤供選擇
* 標籤類別/標籤：學習主題/標音符號與運用、識字與寫字、閱讀 （同時選擇國語文、三年級）
* 標籤類別/標籤：學習主題/坐標幾何、關係、代數、函數（同時選擇數學、三年級）
* 標籤類別/標籤：學習表現/4-II-4 能分辨形近、音近字詞，並正確使用（同時選擇國語文、二年級）



1. 只有兩層：平行建立各種類別的標籤
2. 用多層結構：每一層都是標籤，彈性可設定一到三層（更容易指定關聯性）
3. 用多層結構：每一層都是標籤，一定要設定到最小層（跟現在題庫架構一樣）

1&2拿國語跟數學素養來套看看，跟運營約時間
