# 待討論項目

1. K12期望標籤也能用在子題上，因為題組底下子題知識點都可能不同，主要為了準確推薦學生錯誤的知識點，延伸議題如下。
   * 是否題組本身和子題都各別可標籤。(因為題組可能會有和子題不同的情境標籤)
   * 如可以標註到子題，批量標註的部分需思考UX/UI如何設計，目前題目總覽批量相關功能都是先篩出題目為主，不會顯示子題。
   * 呈上題，如果批量標註需大改目前的UI/UX，因子題標籤大多會用在素養題型，所以是否用OP方式處理目前<mark style="color:red;">**已建立**</mark>的素養題庫，未來如有其他新建立素養，教師建立時單題標註就行。
   *   目前學科題沒有什麼題組題目，如果未來有，當用標籤篩選題庫時，篩到題組題時的處理方式。

       * 可能方式：篩選時不去理會子題標籤，只篩題組本身標籤，因為子題篩出來也無法單獨變成題目使用，一樣是要加入完整題組。


2. 目前能力指標標籤和樹狀標籤是否維持併行就好。
   *   因為能力指標還牽扯到學習成果表的雷達圖等，短時間內不好共用或移除。


3.  K12期望未來跟知識點相關的標籤，能夠有類似知識族譜的功能，討論是否分階段執行。( 範例：加法->分數->方程式，代表要先學好`加法`，才會進階到`分數`然後最後是`方程式`)

    * 第一階段：K12先建立完樹狀標籤，並且已大量標註到題目上。
    * 第二階段：執行知識點族譜的功能，可針對知識點的標籤建立族譜。
    * 第三階段：運用錯題題目練習推薦上，系統推薦不熟的知識點，前置需要練習的題目。


4. 討論是否能有建立樹狀標籤的相關套件，方便教師進行建立和篩選標籤時呈現。
   * 套件最好也能有拖拉功能。
