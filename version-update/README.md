# SP248版本更新(2025/1/20，2/6)

### 更新日期：2025/1/20 & 2025/2/6

### 遊戲相關優化：&#x20;

1. 奪寶信號能量回復規則調整。&#x20;
   1. 將奪寶信號預設能量回覆速率1000改為1。
   2. &#x20;從電競後台調整能量值上限設定後，會影響「能量回復倍率」。
2. 遊戲介面調整。
   1. 電競馬來文案，Malay 改成 Bahasa Malaysia。&#x20;
   2. 結算畫面加入錯題回報按鈕。&#x20;
   3. 遊戲內自選章節，隱藏未分類且0題的題庫。
3. 題組首次答對傷害力加成2倍。
   1. 每個課程世界都可設定是否開啟2倍加成。
4. 地形新增：
   1. 國泰地形：領導員－小樹老師，道具：夢想露營燈&#x20;
   2. 國泰地形：攝影員－玲玲，道具：逐夢照相機&#x20;
   3. 素養地形：魔法夜語者，道具：魔法喵罐頭&#x20;
   4. 麻辣燙攤，道具：麻辣燙&#x20;
   5. 金牛座，道具：金牛星座卡
5. 道具新增&#x20;
   1. 數字地形寶箱

### 題庫管理後台優化：

1. 調整題目輸入框最大高度的上限，可以看到更完整多媒體內容。
2. 批量上傳 - 加入能力指標欄位。
   1. 批量上傳新增W欄「能力指標」，上傳會存入資料庫但不會顯示。
3. 題目總覽-批量編輯題目功能優化。
   1. 題目總覽勾選題目功能，增加可勾選題目的操作範圍，避免誤觸開啟題目預覽。

### 教師後台優化：

1. 教師後台 Sidebar，增加「學習數據」層級。
2. 新數據頁面：
   1. 『班級任務列表』：依據任務模式（一般、測驗、魔王、競賽之盾），呈現該班級該任務的平均數據以及未完成名單
   2. 『單一任務數據』：可看到任務的詳細資訊、該班級學生的作答進度以及每個學生的作答數據。
3. 新增『新增作業』，調整如下。
   1. 記憶使用者選擇的題目來源相關設定。
   2. 記憶使用者在任務設定的「答題顯示設定」。
   3. 教師後台取消派發素養任務後，師生都無法看到任務相關資料與數據（任務進入「canceled」狀態）。

### 產品機制變更：

1. 使用者觸發素養任務補派發機制（教師後台重派素養任務/完成首任務/縣市後台重新授權等)，且有多個任務處在 「canceled」 狀態時，系統僅會復原屬於當前學年學期的 canceled 任務。
2. 針對教師後台取消素養任務與補派發機制建立開關（預設開），有問題時 RD 可緊急關閉。
