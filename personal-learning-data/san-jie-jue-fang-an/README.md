# 三、解決方案

## 功能(Key Features)&#x20;

1. 個人學習數據 『 已完成任務列表 』 文案改為 『 已完成素養任務列表 』 。
2. 個人學習數據新增 『 已完成班級任務列表 』 的分頁。
3. 已完成班級任務列表，可查看內容如下。
   1. 可透過日期區間篩選已完成的一般任務列表。(沿用目前學習數據 『 [已完成任務列表 ](https://www.pagamo.org/learning_data/student/4174052/finished_missions)』 設計方式)
   2. 可透過日期區間篩選已完成的測驗任務列表。(沿用目前學習數據 『 [已完成任務列表](https://www.pagamo.org/learning_data/student/4174052/finished_missions) 』 設計方式)
   3. 上述任務都能查看當時完整的作答記錄。(沿用目前教師後台 『 [班級作答記錄裡的個人任務數據](https://www.pagamo.org/api/teacher_console/learning-data/class-mission/classes/589097/answer-log/jcmY-ZMitNe5kv03tonuVvFhxAzo2Wa9E1OaFatUL5w?generalMissions=MJurFO9KIf6a9U1FBo9Cn0Gyj6VgqDGujfa2FgMP02AdfH5wrj4v0NB_-CBXKj7oWjKSsX1G33H-LPCLiR6ZLg) 』 設計方式)
4. 優化申論題作答記錄的內容，學生在查閱申論題記錄時可以看到老師或AI批閱的結果。

## 用戶流程(User Flow)

1. 用戶登入後 -> 頭像內選學習數據 -> 選擇已完成班級任務列表 -> 篩選自己想要查看的任務。
