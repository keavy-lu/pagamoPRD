# 三、解決方案

## 功能(Key Features)&#x20;

1. 管理者介面>使用者帳號管理>
2. 列表：操作>...選單新增第四個選項：重設密碼
3. 欲修改的帳號操作>...點擊「重設密碼」
   1. 開啟彈窗
      1. 標題：重設密碼
      2. 文字： 請再次確認要重設密碼的帳號 目前的帳號：\[顯示該帳號]\
         輸入欄\
         placeholder:請輸入帳號
      3. 文字：請輸入新密碼\
         輸入欄\
         placeholder:輸入8 碼以上英文或數字
      4. 按鈕
         1. 取消：關閉彈窗，不做任何儲存和改變
         2. 確定：
            1. 未完整輸入正確資訊前是disabled狀態
            2. 帳號輸入正確是指定的該帳號，且密碼符合規則，確定按鈕才會是 primary 可點擊狀態，按下後該帳號的密碼更新。

## 用戶流程(User Flow)

1. 管理者可以在後台快速修改單一帳號的密碼
2. 設定過程有確認目標帳號正確
