## 功能(Key Features)&#x20;

1. 電競後台報名者管理搜尋和列表加入UID、隊伍代碼
   1. 搜尋列新增搜尋目標
   2. 列表新增欄位
2. 電競後台（含奪寶信號）/官方競賽/教師競賽之盾賽後報表加入學校、年級、班級欄位
   1. 電競後台（含奪寶信號）
   2. 官方競賽
   3. 教師競賽之盾
3. 電競後台匯入帳號功能
   1. 匯入參賽名單後台
      1. 下載範例檔
      2. 匯入
      3. 匯入紀錄
   2. xlsx檔案內容規格
   3. 詳細請參考：[PM Wireframe](https://www.figma.com/design/uSFGutGzzY9AMwVE7cvXJd/%EF%BC%83-42519-%E9%9B%BB%E7%AB%B6%E9%81%8B%E7%87%9F%E6%95%88%E7%8E%87%E6%94%B9%E5%96%84?node-id=7910-2464\&t=S8OICYxd7f0nj9QO-4)

## 用戶流程(User Flow)

1. 電競後台報名者管理搜尋用戶可使用UID/隊伍代碼
2. 賽後要分析、提供資料給縣市政府、學校，無需再對應UID補上相關學籍資料
3. 可在電競管理後台直接匯入參賽名單，取代手動報名。
