# 機制說明手冊

## 報名成功頁賽事推薦機制 規格與操作指南

***

### I. 功能與操作概覽 (User Manual View)

#### 功能目的

報名成功頁賽事推薦機制（Recommendation Feature on Registration Success Page）旨在最大化用戶在平臺上的參與度。當用戶成功報名一場電競賽後，系統立即展示其他**正在開放報名**的優質賽事，藉此：

* 提升用戶在多場賽事的註冊率。
* 利用報名成功後的「高意圖時機」進行有效的賽事導流。
* 提供營運團隊精準追蹤不同賽事之間的報名來源。

#### 操作指引 (運營設定)

此功能主要由電競管理後台控制，運營人員需在各別賽事的後台設定中手動啟用推薦。

1. **設定位置**：進入特定電競賽事的 **電競管理後台** > 報名頁設定。
2. **開關設定**：確保 **推薦賽事開關** 處於開啟狀態。
3. **條件滿足**：只有當賽事符合所有顯示條件（詳見規格細節）時，才會出現在其他賽事的報名成功頁上。

#### 數值影響與追蹤說明

此功能不涉及地圖或座標數值設定。主要的影響在於數據追蹤能力：

* **報名來源追蹤**：所有通過推薦區點擊的連結，都會自動加上 `utm_source=finished` 參數。
* **後台數據呈現**：當後台下載報名表單時，報名入口（或報名媒介）將顯示為 **finished**，以便營運人員評估此推薦機制帶來的實際轉換效果。

***

### II. 產品規格細節 (Specification View)

#### 核心規格

| 項目        | 規格細節                                    |
| --------- | --------------------------------------- |
| **預設狀態**  | 預設為關閉。需在後台手動開啟 **推薦賽事開關**。              |
| **適用地圖**  | 適用於所有有報名網址的電競管理後台創立的賽事地圖。               |
| **排除例外**  | **不**適用於 **奪寶信號** 類型的賽事。                |
| **空列表處理** | 若無任何符合條件的推薦賽事，則整個 **推薦賽事區**（包含引導文案）不顯示。 |
| **排版規則**  | 若推薦賽事數量為 1 或 2 則，靠左排列顯示。                |

#### 推薦賽事顯示與排序邏輯

系統僅列出符合下列**所有**條件的賽事：

**1. 顯示條件（過濾邏輯）**

* 該賽事在後台已開啟 **推薦賽事開關**。
* 該賽事正處於 **正在開放報名期間**。
* 該賽事必須提供有效的報名網址。
* 當前登入的用戶帳號 **尚未報名** 該場比賽。
* **共用報名頁情境處理**：若該用戶已報名某一組共享報名頁的賽事，則該組所有賽事皆不列入推薦清單。

**2. 排序規則**

所有符合顯示條件的賽事，依照 **報名截止時間** 進行排序：

* **優先順序**：截止時間越近的賽事，優先顯示在列表越上方。

#### 介面元素與欄位要求

推薦賽事區（**推薦賽事選單**）由下列元素組成，並要求在介面不足時進行截斷處理：

* **引導文案 (若有推薦)**：`其他比賽也在開放報名，快來一起加入吧！`
* **圖片 (活動橫幅)**：
  * 圖片來源為電競報名頁設定的活動橫幅。
  * 需縮小比例顯示。
  * 若無上傳橫幅，則顯示預設圖。
* **比賽名稱**：
  * 顯示電競報名頁設定的比賽標題。
  * 若介面空間不足以完整顯示，尾行最後一字需以 `...` 取代。
* **報名時間格式**：
  * 僅顯示日期，不顯示時、分。
  * 格式為：`YYYY/MM/DD - YYYY/MM/DD`
* **前往報名按鈕**：
  * 點擊後必須 **另開分頁** 打開該賽場的報名頁。
  * 開啟的網址應根據用戶當前語系決定。

#### 錯誤處理與追蹤參數

| 項目         | 描述                                                                                                     |
| ---------- | ------------------------------------------------------------------------------------------------------ |
| **錯誤提示**   | 無。若無推薦賽事，則不顯示該區塊。                                                                                      |
| **UTM 參數** | 開啟報名頁的網址尾巴必須強制帶入 `utm_source=finished`，用於後續追蹤報名來源。                                                     |
| **範例網址**   | `https://esports.pagamo.org/register/.../information?utm_source=finished`                              |
| **語系處理**   | 若用戶處於非預設語系（例如 zh-TW），網址需同時帶入語系參數：`esports.pagamo.org/.../information?locale=zh-TW&utm_source=finished` |
