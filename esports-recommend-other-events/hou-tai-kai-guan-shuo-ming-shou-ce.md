# 後台開關說明手冊

## 後台推薦賽事顯示設定 規格與操作指南

### I. 功能與操作概覽 (User Manual View)

#### 功能目的

「推薦賽事顯示設定」旨在控制當玩家成功完成本次賽事報名後，是否允許本次賽事被納入推薦列表，顯示於報名成功頁面下方。

* **解決問題：** 讓公開報名的賽事能夠在其他相關賽事的報名成功流程中曝光，提高玩家參與度與賽事間的引流效果。
* **建議操作：** 此功能**強烈建議**僅針對對外公開招募的比賽開啟。

#### 操作指引

此設定位於競賽管理後台，控制是否將該賽事設為可推薦的候選名單。

* **後台位置：**
  1. 登入 **競賽管理後台**。
  2. 導航至左側選單的 **報名頁設定**。
  3. 進入 **基本設定** 。
  4. 找到收合區塊 **推薦賽事顯示設定**。
* **數值設定與操作：**
  * 管理員需操作一個 **開關 (Toggle Switch)** 來決定是否開啟此功能。
  * **文案提示：** 此報名頁可以在報名成功後於頁面被推薦（公開報名的比賽才建議開啟）。
  * **設定效果：** 若開關設為**開啟**，則該賽事將具備在其他賽事的 **報名成功頁** 推薦版面顯示的資格（顯示與否仍需依賴前端推薦邏輯的最終判斷）。

### II. 產品規格細節 (Specification View)

#### 核心規格

| 規格項目        | 說明細節                                       |
| ----------- | ------------------------------------------ |
| **功能名稱**    | 推薦賽事顯示設定                                   |
| **後台路徑**    | 競賽管理後台 > 報名頁設定 > 基本設定                      |
| **控制類型**    | 開關 (Toggle Switch)                         |
| **預設狀態**    | **預設關閉 (Default OFF)**                     |
| **適用地圖類型**  | 僅適用於「一般電競賽」（包含一般地圖與特殊地圖）。                  |
| **不適用地圖類型** | **奪寶信號** 賽事後台不應顯示此功能。                      |
| **前端影響**    | 該開關設為 ON 是賽事出現在 **報名成功頁** 推薦區塊的**判斷條件之一**。 |

#### 欄位要求與錯誤處理

**1. UI 元素與文案要求**

* **區塊標題：** 推薦賽事顯示設定
* **輔助文案 (Helper Text)：** 此報名頁可以在報名成功後於頁面被推薦（公開報名的比賽才建議開啟）

**2. 邏輯判斷與隱藏機制**

系統需在載入 **競賽管理後台** 時，判斷當前賽事的類型，以決定是否顯示此設定區塊。

* **顯示條件：**
  * `Contest Type` = `一般電競賽 (General Esports)`
* **隱藏條件：**
  * 若 `Contest Type` = `奪寶信號 (Treasure Hunt Signal)`，則必須 **完全隱藏**「推薦賽事顯示設定」整個收合區塊。

**3. 儲存與同步**

* 此設定的開關狀態需與其他基本設定同步，透過點擊底部的 **儲存** 按鈕寫入資料庫。
* 此設定的狀態更新後，應立即影響前端 **報名成功頁** 的推薦賽事列表撈取邏輯。
