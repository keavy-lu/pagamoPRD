# 二：問題與目標

目標：同世界的老師和學生可以更快速方便的建立師生關係（自建班級）

## 目標用戶

同世界會使用自建班級的老師和學生

## 主要問題定義

目前教學者和學習者建立班級關係的方式與流程：

1. 學習者透過輸入班級代碼加入班級遇到的問題
   1. 班級代碼是英數混合亂碼，系統顯示大寫，但並未標註班級代碼不區分大小寫
   2. 輸入班級代碼時會有各種狀況，例如：切換英數、大小寫、打字慢，影響教學者上課時間
   3. 進入PaGamO預設是到上次離開的課程世界，常常沒注意是否進入正確的世界加入班級
   4. 班級代碼加入班級的流程：
      1. 教學者需引導學習者進入正確的課程世界，教師後台->我的班級->提供班級代碼
      2. 學習者需進入正確的課程世界-> 點擊「我的班級」 ->輸入班級代碼（無需區分大小寫），才可加入班級
2. 教學者在教師後台輸入該世界學生帳號，將學習者加入班級遇到的問題（公開世界不開放此功能，註1）
   1. 老師需額外搜集學生帳號，並輸入正確，才可事先將學習者加入班級
   2. 匯入學生流程：教師後台->新增學生->匯入學生->貼上學生帳號

現有方式會花費教學者跟學習者較多的時間，因將學習者加入班級是教學者指派任務給學習者前必經的步驟，不論是在課堂中、研習中、客戶demo的情境，此功能使用體驗會是讓教學者選擇是否繼續使用的關鍵。



## 解決方向（High Level Approach）

1. 本專案不處理系統班級，僅處理自建班級。目前班級有自建班級與系統班級兩個類別，系統班級已有自動加入、封存、退出班級機制，
   1. 系統班級：
      1. 縣市世界 1-9 年級系統會自動建立系統班級，包含教育雲、澔學、批量創建班級。目前教育雲、澔學有自動加入、封存、退出班級的機制，若帶入資料中沒有該班級資訊，學生會被自動退出班級
   2. 自建班級：老師自己創建的班級。公開世界、縣市世界老師因有學扶班級、混齡班級、（花蓮）社團機構的情境，會額外建立「自建班級」使用（註1）
      1. 公開世界（國小天地、國中世界、高中職世界)自建班級數量：210,903
      2. 縣市世界自建班級佔所有班級比例：44.8%（34,601/77,178）
2. 教育部推動「中小學數位學習精進方案」（註2）
   1. 自111年至114年，針對全國中小學 1 年級至 12 年級全面推動數位學習精進計畫，達成「班班有網路 生生用平板」。
   2. 配發總量達到偏遠地區學校學生載具比率為1:1；非偏遠地區則以學校班級數每6班補助1班方式配發，教師依課程教學與數位學習需求輪流借用，達到生生用平板目標。
3. 解法一：學生掃描QRCode直接加入班級
   1. 老師端：
      1. 教師後台/我的班級，自建班級新增班級QRCode/連結（類似Line群組）
      2. QRCode/連結可新增在「邀請學生」頁面，並同時教老師引導學生加入班級
   2. 學生端：
      1. 可以掃描透過QRCode直接加入指定世界的班級中
      2. 已登入PaGamO並已有該班級課程世界權限->成功加入班級
      3. 已登入PaGamO但沒有該班級課程世界權限-->加入班級失敗，你尚未加入此班級的課程世界，加入班級失敗。 要有此班級課程世界的權限才可加入班級，請詢問提供班級 QRCode 的老師。
         1. 未登入PaGamO已有該班級課程世界權限-> 引導其登入，判斷有無該班級課程世界權限，有->1
         2. 未登入PaGam也沒有該班級課程世界權限-->引導其登入，判斷有無該班級課程世界權限，無->2
4. 解法二：學生掃描 QRCode 幫忙帶入班級代碼
   1. 老師端：
      1. 教師後台/我的班級，自建班級新增班級QRCode
      2. 老師須先引導學生到指定課程世界，掃描QRCode，才可成功加入
   2. 學生端：
      1. 需先進入正確的課程世界，
      2. 至「我的班級」掃QRCode自動帶入班級代碼按下「送出」，才可成功加入
5. 解法三：學生輸入的班級代碼數字化，並在首頁可輸入
   * 現有班級代碼維持英數混合，另外產出「數字代碼」讓學生可在在首頁、我的班級輸入已加入班級
   * 點擊輸入框可以只出現數字鍵盤
   * 缺點：
     * 數字代碼解法較複雜，後端開發班級QRCode較單純
     * 首頁可輸入班級代碼加入班級：app審查可能會不過，因為會被認為是輸入優惠代碼，屬於購買行為

## 目標與衡量指標

同一個世界中，學生可以透過掃描老師提供的班級 QRCode ，快速加入自建班級中

### 目標

1. **自建班級會自動產出「加入班級連結」與「班級QRCode」**
   1. 自建班級皆可使用此功能（老師和學生皆要操作才可建立班級關係）
   2. 教師後台新增加入班級連結、班級QR Code
      1. 加入班級連結：
         1. 老師可複製「加入班級連結」給學生
         2. ~~老師可隨時更新「加入班級連結」，防止連結外傳造成非本班學生加入班級的情況~~
         3. 新增說明讓老師理解加入班級連結的使用流程並可帶著學生依步驟操作
      2. 班級QRCode：
         1. 老師可直接點擊「班級QRCode」，即可呈現在QRCode讓學生直接掃描
         2. ~~老師可隨時更新「班級QRCode」，防止QRCode外傳造成非本班學生加入班級的情況~~
         3. 新增說明讓老師理解班級QRCode使用流程並可帶著學生依步驟操作
2.  **讓學生更快速方便加入老師的自建班級中：**

    1. 學生可透過點擊「加入班級連結」、掃描「班級QRCode」加入班級
       1. 已登入且有課程世界權限，即可加入該班
       2. 已登入但未有課程世界權限，讓使用者知道加入班級失敗的原因
       3. 未登入，先引導使用者登入再走1、２





### 非本次目標（產品目標之一，只是這次先不做）

<details>

<summary>系統班級不會有班級QRCode</summary>

系統班級中，教育雲與澔學已有自動封存、退出班級機制，因此若學生透過QRCode加入班級，但帶入資料是錯誤的也會被退出班級。

* 教育雲班級
* 澔學班級
* 帳號管理後台與管理者後台創建的班級
  * 期待帳號管理後台與管理者後台批量創建班級可以有讓學生透過班級QRCode加入班級的功能



</details>

### 成功的衡量方式

1. 教師研習時會使用到此功能，快速搜集老師反饋
   1. 不建議花太多時間搜集回饋，快速獲得老師反饋即可
2. 後續追蹤功能使用率：有開放此功能的世界，透過QRCode或是班級代碼加入自建班級的使用狀況
   1. 可透過 GA Event 追蹤
   2. 沒辦法驗證是否有解決到問題
