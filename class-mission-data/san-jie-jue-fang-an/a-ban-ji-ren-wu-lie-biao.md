### A- 班級任務列表

* 可以依照班級、時間、模式、科目等篩選出想看的任務數據
* 可以搜尋任務/競賽名稱找出想看的任務數據
* 依照不同任務模式「班級視角」任務數據欄位不同

分成下述幾個區塊

1. 篩選器區塊
2. Tab 區塊
3. 班級任務數據表格區塊

#### A-1 篩選器區塊

*   班級下拉式選單

    * 此欄位必填、單選
    * 班級任務需先有班級才可指派班級任務，所以若無班級，下拉式選單會呈現disabled，並會在下方引導老師至「我的班級」去創建班級（見下圖一）&#x20;
    * 預設為班級列表第一個班級，若老師有選擇過班級，前端會紀錄老師上次選擇的班級（local Storage）（討論串）， 素養任務跟班級任務的班級下拉選單local storage不會共用，用戶在素養任務、班級任務會個別記錄上次使用的班級
      * 舉例：素養任務班級選擇601，用戶跳到班級任務頁面時，若上次進入班級任務時，沒有選擇班級601，用戶要在自己調整到601
    * 班級資料來源：「我的班級」頁面的班級，若有年級folder，就會顯示年級folder分類
    * 點擊後會有搜尋班級的功能，素養任務只抓有年級folder的班級，而班級任務除了年級folder外，還會有「無年級」的班級&#x20;



    <figure><img src="../.gitbook/assets/image (11).png" alt=""><figcaption><p>班級任務列表「無班級」的狀態呈現</p></figcaption></figure>
* 任務開放時間
  * 此欄位必填，預設時間：當天月份的前兩個月後一個月
    * 舉例： 今天11/2，時間區間會顯示9/1-12/31&#x20;
  * 任務開放時間標題旁會加上「tooltip」 文案：最多可選取一年的時間&#x20;
  * 會記錄用戶上次的選擇（local storage）
  * 在此開放時間區間內的任務，會顯示在下方列表，由新到舊排序
* 領域/科目篩選器
  * 此欄位非必填、可複選、可搜尋，取聯集&#x20;
  * 未展開搜尋前的 placeholder：選擇想篩選的科目&#x20;
  * 篩選器展開後裡面的「搜尋」的 placeholder：請輸入科目名稱&#x20;
  * 篩選器資料來源： 撈分頁條件下該任務作業題目的所屬科目&#x20;
    * 該班級&#x20;
    * 該時間區間&#x20;
    * 所有一般、測驗、魔王模式的任務作業以及競賽之盾的作業&#x20;
  * 若某任務模式中沒有該科目的任務作業，該模式的分頁會呈現空狀態&#x20;
  * 只會顯示科目名稱，不會顯示題庫名稱。若有不同題庫一樣的科目名稱只會顯示1次&#x20;
  * 只有該任務作業題目來自該科目，任務就會顯示在下方列表，並以開放時間由新到舊排序
* 搜尋輸入框
  * 此欄位非必填， placeholder：搜尋名稱&#x20;
  * 僅能搜尋任務名稱（競賽之盾是搜尋作業名稱），且為模糊搜尋，與其他篩選器取交集

#### A-3 班級任務數據表格區塊

{% tabs %}
{% tab title="一般模式" %}
* 任務開放時間：&#x20;
  * 定義：任務設定中的任務開始時間，時間顯示24小時制（優化票）
  * 可排序，預設為任務開放時間新到舊排序&#x20;
* 任務名稱：
  * 定義：任務設定中的任務名稱
* 任務狀態
  * 未開放：任務開放時間還未到&#x20;
  * 進行中：任務已開放但還未結束&#x20;
  * 已結束： 任務結束時間已到&#x20;
* 未完成人數&#x20;
  * 可排序
  * 定義： 已點擊「開始任務」但還未按下「完成任務」的學生人數&#x20;
  * 新舊版皆有的問題：加入班級的學生會拿到該班級的所有任務，因此學生在某任務結束後加入班級，該任務未完成人數會顯示該生，但該生無法完成任務&#x20;
  * 此欄位可向下展開看到未完成名單，呈現方式：座號-姓名 若座號、真實姓名欄位為空，同素養數據處理方式&#x20;
    * 沒有座號會留空，例： -真實姓名&#x20;
    * 沒有真實姓名也會留空，例：座號-&#x20;
    * 兩者都沒有，例： -
* 首次平均正確率(Slack討論串)&#x20;
  * 可排序，會加上tooltip 文案：「計算規則：該班學生首次正確率加總 / 該班已完成任務的學生數 x 100%」
    * &#x20;tooltip由設計統一定寬，「/」 和「x」符號間都會有空格（若有地方沒加上，前端可直接補上空格）&#x20;
  * 定義：&#x20;
    * 首次作答平均正確率＝該班學生首次作答正確率加總 / 已完成任務學生數 x 100%&#x20;
    * 首次作答正確率=首次作答正確題數 / 首次作答總題數 x 100%&#x20;
    * 改為學生「完成任務」才會有此欄位數據，若該班還未有學生「完成任務」時，會顯示「--」&#x20;
* 總平均花費時間&#x20;
  * 可排序，會加上tooltip 文案：「計算規則：該班學生完成任務花費時間加總 / 該班已完成任務的學生數」&#x20;
  * 定義：
    * 總作答平均花費時間=學生總作答花費時間加總/已完成任務學生數&#x20;
    * 總作答花費時間：每題作答時間加總（看到題目到按下「送出」的作答時間）且任務中每題要做到全對&#x20;
    * 已按下「開始任務」但還未作答，就會顯示「--」&#x20;
  * 時間顯示：
    * 「 oo 時 oo 分 oo 秒」，
      * 如使用者僅花費 34 秒，就顯示 「34 秒」，
      * 如超過60分鐘就會變成 oo 時 oo 分oo秒，翻譯：oo h oo m oo s&#x20;
* 科目&#x20;
  * 會顯示該任務題目所屬的科目
  * 依照欄寬顯示科目標籤，超過欄寬則用「...」表示(見與設計討論comment）&#x20;
  * 若含有多個科目，會依資料庫回傳的順序，「通常（但不保證）」會接近科目建立時間排序（slack討論串）&#x20;
  * 科目顯示上限設定為 5 個（原本為限制兩行，但前端發現 Antd 沒有提供這樣的功能，要自己刻出這個功能會花時間）（討論連結）&#x20;
* 操作：
  * &#x20;查看內容：&#x20;
    * 點擊後開啟題目預覽drawer&#x20;
    * 題目順序 不論是「順序」、「隨機」出題，皆是以出作業「題目預覽」頁的順序呈現&#x20;
  * 任務數據：&#x20;
    * 點擊後會進入「單一任務數據頁面」 「單一任務數據頁」會顯示學生作答該任務的即時數據，且在該班「未開放」任務可能已有學生完成（學生同時在多班拿到同樣任務），因此「任務數據」按鈕不會呈現disabled&#x20;
    * 未開放且尚未有學生開始作答、完成任務，在單一數據頁面會顯示空狀態
{% endtab %}

  * 定義：&#x20;

* 總平均花費時間&#x20;
  * 可排序，會加上tooltip 文案：「計算規則：該班學生完成任務花費時間加總/該班已完成任務的學生數」&#x20;
  * 定義：&#x20;
    * 平均花費時間=完成任務學生花費時間加總/完成任務學生數&#x20;

    * 完成任務學生花費時間：看到題目到按下「送出」、「直接送出」的作答時間加總&#x20;
    * 學生點擊「完成任務」才會有此欄位的數據，若還未有數據時，顯示「-」&#x20;

    * 若該班級該任務還未有學生完成任務，則「任務數據」按鈕呈現disable，用戶也無數據可以觀看

{% tab title="魔王模式" %}
* 任務開放時間：同「一般任務」&#x20;
* 任務名稱：同「一般任務」
* 任務時長（決定不加此欄位） 在單一任務數據中顯示即可&#x20;
* 任務狀態&#x20;
  * 依照任務狀態顯示狀態名稱，狀態定義：
    * 未開放：任務開放時間還未到&#x20;
    * 進行中：任務正在進行中&#x20;
    * 已結束：任務結束時間到、提早擊敗魔王、全班提早淘汰都算是已結束（[優化票](https://redmine.bonio.com.tw/issues/41291)）&#x20;
* 參與人數（Slack討論串）&#x20;
  * 顯示目的：方便老師查看已結束魔王任務的參與狀況
  * 定義：有加入賽場就算有參與。
    * 任務狀態若為「已結束」就會顯示
    * 若賽場已滿，只要有人淘汰，有被指派但還未參與的同學可以再加入賽場&#x20;
    * 若某魔王任務結束後，老師移除原班級某位學生
      * &#x20;「參與人數」會因為老師踢掉學生而減少，變成9人
      * &#x20;「單一任務數據頁」不會顯示被踢掉學生的數據
      * &#x20;「魔王戰排行榜」會顯示被踢掉的學生排名與積分 ，避免排名缺漏造成誤會
        * 理想狀況：排行榜要能分辨出已不在此班級的學生（但因學生轉學、轉班情況發生機率較小，此項目未來有需求在優化即可）&#x20;
* 平均正確題數
  * 可排序，會加上tooltip 文案：「計算規則：有作答學生此任務不重複的答對題數 / 有作答此任務的學生數」&#x20;
    * 平均數據會四捨五入至小數點第一位
  * 定義：有作答學生此任務不重複的答對題數/有作答的學生數
  * 任務狀態若為「已結束」就會顯示
* 科目：同「一般任務」&#x20;
* 操作&#x20;
  * 查看內容：同「一般任務」
  * 任務數據：&#x20;
    * 點擊後會進入「單一任務數據頁面」 若是「未開始」的魔王任務：「任務數據」按鈕 disabled

> Q\&A

1. 魔王任務、競賽之盾為什麼呈現「平均正確題數」而非「平均首次作答正確率」？
   1. 魔王、競賽之盾多數使用情境為「複習」，都是短時間快速作答某任務以達到遊戲成就，因此老師想知道該任務是否有被做完、有無答到正確（重複答題的資訊對老師來說不重要），因此單一任務數據頁會顯示每個學生的「未答題數」、「正確題數」
   2. 單一數據頁面數據調整後，班級任務列表的魔王任務、競賽之盾數據就隨之調整為「平均正確題數」，讓老師知道該班學生平均有作答到正確的題數
{% endtab %}

{% tab title="競賽之盾" %}
* 競賽開放時間：&#x20;
  * 老師按下「開始競賽」倒數10秒後的時間&#x20;
  * 預設由新到舊排序
  * 有開賽的競賽之盾才會顯示在此（班級任務列表/競賽之盾）&#x20;
    * 只要老師沒有按下「開始競賽」，學生就無法進入賽場答題，就不會出現在教師後台/競賽之盾列表中&#x20;
* 競賽資訊：&#x20;
  * 賽場代碼：每個賽場都會有賽場代碼，競賽設定後按下「開放進場」即會產生&#x20;
  * 競賽種類： 大亂鬥、團體戰&#x20;
  * 競賽時長（預計會放在單一任務數據頁面中）：&#x20;
    * 競賽時長＝競賽結束時間-競賽開始時間
    * 競賽結束時間：&#x20;
      * 老師按下「結束競賽」倒數10秒後的時間， 若老師按下「開始競賽」但最後忘記按下「結束競賽」按鈕，當天00:00會檢查競賽代碼（按下開放進場」按鈕）生成後超過六小時，仍未關閉時系統主動關閉。競賽時長最長會是24+5:59:59 。
      * 若競賽還未結束，競賽時長顯示「--」&#x20;
      * 補充競賽之盾邏輯：每天 00:00 會檢查已「開放進場」但尚未「開始競賽」的課堂競賽，若「開放進場」的時間小於六小時前 (如 9/30 00:00 會檢查時間小於 9/29 18:00 的），會自動把這個賽場關閉。這個邏輯只有在正式機會執行，develop / release 會是中午12:00執行此規則（Slack討論、開票）&#x20;
* 作業名稱：&#x20;
  * 顯示該賽場選擇的作業名稱
  * 補充機制：目前每個作業可以開啟多場競賽之盾，因此會有同份作業但賽場代碼不一樣的狀況&#x20;
* 參與人數：&#x20;
  * 可排序，會加上tooltip 文案：「僅計算此班級有參與本場賽事的學生人數」&#x20;
  * 只要為開賽者任意班級的學生，輸入賽場代碼即可加入賽場，此欄位只顯示此班級有加入過該賽場的人數（非每場競賽所有參與人數）&#x20;
  * 開賽但無人加入賽場，參與人數會顯示「--」（討論串、comment）&#x20;
* 平均正確題數&#x20;
  * 可排序，會加上tooltip 文案：「計算規則：該班有作答本場賽事學生的不重複答對數 / 該班該賽事有作答的學生人數」 &#x20;
  * 定義：該班有作答本場賽事學生的不重複答對數 / 該班有作答本場賽事的學生人數&#x20;
    * 平均數據會四捨五入至小數點第一位
* 科目：
  * 同「一般任務」&#x20;
* 操作
  * 查看內容：同「一般任務」
  * 競賽數據： 點擊後會進入「單一任務數據頁面」 若是沒有開始的競賽之盾不會出現在此頁面。若競賽期間沒有學生加入賽場，「競賽數據」呈現空狀態，「競賽數據」按鈕為disabled。
