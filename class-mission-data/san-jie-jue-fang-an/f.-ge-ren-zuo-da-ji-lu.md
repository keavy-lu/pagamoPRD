### 作答記錄概覽

{% tabs %}
{% tab title="一般、測驗模式" %}
一般、測驗模式

* 此區塊數據會在「完成任務」後出現，未完成任務時會呈現「空狀態」
* 正確率：
  * 與單一任務數據/一般模式/任務已完成的首次正確率計算規則一致（連結）
  * 定義：首次作答正確題數 / 首次作答總題數（任務總題數）x100%，顯示數據：四捨五入到小數點第一位
* 答對題數：
  * 與單一任務數據/一般模式/任務未完成的首次答對題數計算規則一致
  * 定義：學生在此任務所有題目（包含子題）的答對題數
* 花費時間：
  * 與單一任務數據/一般模式/任務已完成的首次花費時間計算規則一致（連結）
  * 定義：每題首次作答看到題目到按下「送出」的時間加總
  * 花費時間以「分鐘」呈現，如使用者花費82分鐘，就會顯示「  82 分 oo 秒」；如使用者僅花費 34 秒，就顯示 「34 秒」，翻譯： oo m oo s
{% endtab %}

{% tab title="魔王模式" %}
魔王模式

* 此區塊數據會在「魔王任務結束」後出現，名稱改為「作答記錄」，任務未結束時會呈現「空狀態」
* 未答題數：
  * 與單一任務數據/魔王模式/未答題數定義一致（連結（第四點））
  * 有幾種顯示狀況：
    * 未參與會顯示：「--」
    * 參與但完全沒有作答的學生：顯示「該任務題數」（經討論後，此狀況不需特別用紅色標注出來）
* 正確題數
  * 與單一任務數據/魔王模式/未答題數定義一致（連結（第五點））
  * 有幾種顯示狀況：
    * 未參與：顯示「--」
    * 參與但完全沒有作答的學生：顯示「（未作答）」（經討論後，此狀況不需特別用紅色標注出來），避免納入平均正確題數計算
    * 點擊「x」算答錯，也算在作答題數中
* 花費時間：
  * 魔王模式不需要顯示首次花費時間，因每個學生答題速度不同，首次答題數量也不同，顯示花費時間較難做比較
{% endtab %}

### 錯題歷程

* 此區塊數據會「即時出現」：方便老師更即時找出需要幫助的學生
* 錯題次數
  * 可排序，預設會是以高到低排序
  * 降冪：「錯誤（高到低）」> 「正確」>「已作答」
  * 升冪：「已作答」> 「正確」>「錯誤（低到高）」
  * 已作答：只有申論題會有此狀態
  * 定義：該題目在答對前，錯題的次數（亦即答題次數-1(答對次數））
* 題型
  * 可篩選
  * 篩選器中只會顯示該任務有的題型
  * 會有的題型：題組、選擇題、是非題、填充題、申論題
* 題目預覽
  * 只要共用內容、題目、選項中有多媒體內容，就會在題目最前面顯示「標註icon」，點擊後會出現tooltip：「含有「icon」代表該題目、選項含有多媒體內容，題目可能顯示不完整，可點擊「查看內容」瀏覽完整題目、選項。」&#x20;
  * Mathtype 會顯示完整數學公式，此部分須與前端設計討論最大高度、寬度限制，超過會以「...」方式呈現
  * 多媒體素材（圖片、影片、音檔、iframe嵌入、Youtube嵌入、表格）本身不顯示也不轉換成純文字顯示
  * 若共用內容、題目、選項中只有多媒體內容，會在標記icon後面顯示「（多媒體內容）」
* 題目資訊
  * 該題目所屬題庫>科目>冊次>章節
  * 顯示方式與題庫管理後台規則一致：最多只顯示一個「未分類」(Slack連結）
  * 目前多數任務只會派同個科目的題目，本次先不做科目的篩選功能
* 首次花費時間
  * 可排序
  * 定義：該題目第一次作答所花費的時間
* 操作
  * 查看題目：預覽題目的drawer
    * 單題：會直接跳到該題目的頁面
    * 題組：顯示預覽題目的drawer，呈現第一個子題題目與選項
* 答題記錄
  * 單題（選擇、是非、填充、申論）跟題組（題組選擇、題組申論）都可展開答題記錄
  * 目前尚未處理 PDF 題型（2025/05)，不顯示PDF題目與選項，上面的數據依然會計算 PDF 的題型
    * 補充資料：含有多媒體素材的題目佔官方題庫的40％，只有多媒體素材的題目不到1％
  * 會以歷次作答為單位呈現：
    * 單題：
      * 第幾次作答：該學生在此任務中第幾次作答此題目
      * 花費時間：該學生在此任務中每次作答此題的花費時間
      * 作答內容：學生在此任務中每次作答的答案內容。選擇題、是非題顯示學生答案選項內容
      * 對錯記錄：答錯->會在作答內容欄位背景會顯示紅色，錯誤選項會顯示錯誤icon，答對不會有正確icon；答對->背景不會有底色。若學生該題目未作答，會顯示上方「答錯規則」，並在作答內容顯示「未作答」。
    * 題組：
      * 第幾次作答：同單題呈現
      * 花費時間：同單題呈現（完成一次題組題目的時間）
      * 題號：呈現題組中的題目順序
      * 題型：目前僅會有選擇、申論
      * 作答內容：同上方單題紅字第一階段、第二階段描述
      * 對錯記錄：答錯->會在題號、子題題型、作答內容欄位背景會顯示紅色，錯誤選項會顯示錯誤icon，答對不會有正確icon；答對->背景不會有底色。若學生該題目未作答，會顯示上方「答錯規則」，並在作答內容顯示「未作答」。
      * 作答記錄
        * 顯示規則同「題目預覽」
