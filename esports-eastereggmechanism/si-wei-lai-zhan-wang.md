# 四：未來展望

## 彩蛋題機制的未來展望：

初期慈濟會先使用來舉辦電競賽，如比賽順利進行，BD會陸續推廣至其他合作廠商，**當合作廠商已有一定規模使用**，會針對機制進行更多優化，讓電競賽可以增加更多元素。

<mark style="color:red;">**預計未來可能優化項目如下：**</mark>

1. 後台開放自訂彩蛋按鈕的觸發條件。( EX：連續答對X次、訓練X塊土地、攻打X塊土地、隨機等條件)
2. 後台可自訂彩蛋題有機會獲得的道具和機率。
3. 後台可自訂遊戲內彩蛋按鈕的圖案和文字。
4. 後台可設定彩蛋按鈕是否需要答題。

## 優化後的價值：

{% hint style="info" %}
1. 可以透過不同的觸發條件，搭配上不同的道具，讓玩家每次比賽都需要動腦重新思考策略。
2. 因為可獲得的道具會有運氣成分，替比賽增加不確定性，讓賽事更加刺激。
{% endhint %}
