# 三：需求解決方案

{% hint style="info" %}
#### <mark style="color:red;">支援系統：</mark>

APP、WEB、MOBILE WEB。

<mark style="color:red;">**支援的電競模式：**</mark>

班級競賽之盾、一般電競賽、奪寶信號電競賽、特殊地圖電競賽。

<mark style="color:red;">**備註：**</mark>

APP不需支援競賽之盾。
{% endhint %}
