## 重要邏輯(Key Logics)&#x20;

1. 比賽資訊出現在可報名的賽事頁面的邏輯
   1. 電競後台產生
   2. 電競後台：對外公開競賽開關關閉
   3. 目前時間為報名期間內
   4. 比賽尚未結束
   5. 用戶尚未報名完成此場電競賽
   6. 若報名完成，該場賽事轉移進行中的賽事
2. 比賽資訊出現在此參與的賽事頁面的邏輯
   1. 電競後台產生
   2. 以開賽時間決定歸類顯示在哪個年度
   3. 沒有被列為不公開的賽事
   4. 目前時間為已結束（結束後重開起怎麼認定？年度怎麼算）
3. 欄位狀態：
   1. 參與過的賽事-個人排名、隊伍排名
      1. 排名
         1. 前1000名 直接顯示數字
         2. 1001\~最後一名，顯示：1000+
         3. 比賽未結束顯示”- -”
      2. 積分
         1. 直接顯示積分數字
         2. 比賽未結束顯示”- -”
   2. 賽場狀態：依據當前打開頁面時間判斷：
      1. 尚未開賽：當前早於比賽開始時間
      2. 進行中：當前處於開賽期間
      3. 已結束：當前晚於比賽結束時間 （頁面保持開啟狀態下不自動更新狀態，除非重整頁面）
