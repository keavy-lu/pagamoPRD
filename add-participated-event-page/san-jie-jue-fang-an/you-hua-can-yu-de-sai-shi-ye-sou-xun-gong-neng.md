# 優化：參與的賽事頁搜尋功能

需求：<br>

1. 「參與賽事」頁面既有排序是用「賽事開始時間」呈現，無法達到用戶需要的：
   1. 同一系列賽事跨年度一次瀏覽（例如每年的全能電競賽、慈濟電競賽）
   2. 同一年度同一比賽的初複決賽也會因時間相隔太久，夾雜其他比賽（例如：慈濟初賽、慈濟決賽）
   3. 上述情境對於用戶在回顧，以及展示成績、招募隊友時無法準確截圖執行

 方向：<br>

1. 「參與賽事」頁面新增「搜尋功能」，可以解決使用者歷年參加賽事太多，想看他在指定比賽表現的情況（查詢結果也可以作為組隊的依據）。

\
注意事項：<br>

1. 搜尋功能的位置、取消、返回的操作
2. 搜尋時右側錨點（年度）消失
3. 搜尋後仍顯示年度確認 edwin.yip 葉俊緯edwin.yip 葉俊緯  ：有年度會比較好讓玩家區別，建議保留年度
4. 搜尋採取「比賽名稱」關鍵字搜尋

 介面：  \
1\. 新增搜尋欄位  \
2\. 搜尋欄位Placeholder：搜尋比賽名稱\
\
流程：

1. 搜尋：
   1. 搜尋欄輸入關鍵字，按下放大鏡圖示
   2. 比對關鍵字是否符合比賽名稱
   3. 若都不符合，
      1. 搜尋欄顯示該輸入文字，且呈現 Allow clear 狀態
      2. 下方頁面顯示：「 很抱歉，找不到符合的比賽名稱。 我們建議你： 嘗試更換關鍵字 縮短關鍵字搜尋 」
   4. 若有符合，
      1. 搜尋欄顯示該輸入文字，且呈現 Allow clear 狀態
      2. 下方頁面顯示符合的賽事結果
      3. 需保留年度的顯示，將該年度的賽事置於其下，順序是比賽開始日期新的在上舊的在下
   5. 此時右方的錨點功能隱藏 
2. 取消搜尋
   1. Allow clear 狀態的搜尋欄位，清除文字或按下X
   2. 回復到預設狀態
