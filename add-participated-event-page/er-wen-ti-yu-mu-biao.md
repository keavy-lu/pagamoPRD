# 二、問題與目標

## 目標用戶&#x20;

PaGamO玩家

## 主要問題定義

1. 活躍用戶與報名、參加電競人數比例差距大，應有成長空間
2. ~~無法快速得知目前能報名的競賽~~(此問題以別的方案解決）
3. 無法回顧已完成的競賽，也無法得到成就感
4. 希望支援電競達人活動，協助用戶查詢自己年度參賽情況

## 解決方向（High level Approach)&#x20;

完善我的比賽網頁，加上

1. ~~可報名的賽事頁：集中期間可報名賽場列表，方便快速選擇報名~~
2. 已完成的賽事頁：依照年份方便回顧已參與的比賽，並可炫耀競賽成果

## 目標與衡量指標

### 目標&#x20;

1. &#x20;~~遊戲活躍用戶可引流至此看到所有能報名的競賽~~
2. ~~報完名後方便可以繼續報名另一場賽事，拉抬整體報名率~~
3. 已完成的賽事可回顧以供留念
4. 增加答對題數、個人排名、個人積分、隊伍排名、隊伍積分顯示，增加炫耀樂趣和成就感

### 非本次目標&#x20;

1. 營運希望的一鍵報名多場電競賽非本次工項
2. 不提供將獎勵帶回遊戲特定課程的設計
3. 原規劃「可報名賽事」頁將暫停，改其他機制達到推薦競賽的目的，先製作「已參與賽事頁」

### 成功的衡量方式&#x20;

1. 電競達人活動達標人數成長
2. 客服電競活動查詢比賽場數問題降低
