<summary>10/17 會議紀錄</summary>

參與者：峻賓、麗綺、蕙任

會議內容：

1. 評量任務
   1. 有幾間學校的派發日期不同，內容和數量每間學校皆相同
   2. 希望後台可以製作開關，是因為有些學校可能不希望呈現這些數據
   3. 過去會叫特別考題，現在都改叫評量任務（皆是測驗模式）&#x20;
   4. 通常會在學期初和學期末各派發一次（有的學校是學習中和學期末），主要是看學生的進步幅度
   5. 英文素養教材就不會有評量任務，學期成果表可以有第一頁就好
   6. 各校派發時間可以參考此[連結](https://docs.google.com/spreadsheets/d/1Is3Njqzdcfmeo2zXJ89PgjKGjU5aNeN0ksvYqCKbN0U/edit?gid=1260450116#gid=1260450116)
2. 遊戲元素
   1. 本來考慮放虛寶，但虛寶可能有一些效期，或其他討論空間。可以先放人物角色就好
3. PR&#x20;
   1. 期待有個人分別在班級、年級、全國的 PR
   2. 後台也像過去的長條圖設計一樣可以勾選要呈現哪個項目
   3. 有的學校覺得平常最常看到的三個指標為：完成率、正確率、作答時間。因此希望有其他參考指標，PR 則是可以參考學生個人的落點分析
4. 第一面 QR code 連結或許可以調整為 K12 校園網站的連結，後續運營內部再進行討論
5. 時程：期待 11 月底可以先看到改版後的調整
6. 預期只會針對中文、英文製作學期成果表。英文教材背後對應的內容可能會不同（英語素養聯盟、英語素養聯盟入門級、113學年度｜英語素養聯盟入門級），如：磐石、中山工商七年級（可參考此[連結](https://docs.google.com/spreadsheets/d/1Is3Njqzdcfmeo2zXJ89PgjKGjU5aNeN0ksvYqCKbN0U/edit?gid=2128806042#gid=2128806042)）

<summary>11/4 會議記錄</summary>

參與者：峻賓、琬羚、蕙任

會議內容：

1. 113-1 才將評量任務調整為每學期兩次（112-2 暑假向學校說明這個調整）
   1. 過去每週的一般任務已經有四篇文章，每月22號有特別考題的那一週會變成有七篇文章，學生沒有時間在課堂中完成，老師通常會請學生自行回家進行，運營觀察作答狀況並不理想。故後來才調整為每學期兩次的期初＆期末評量（可以測驗的時間約一個半月，期末若要配合成果表的話一個月內需完成）
   2. 選題是教研組進行的，會讓期初＆期末的題目難易度差不多
   3. 112-2 的特別考題只有靜心高中有認真作答，其他學校比較沒什麼在做
   4. 過去特別考題的選題方式比較沒有特別注意相關性，且一開始為品學堂選題，觀察起來沒有什麼脈絡
   5. 評量任務也是續約亮點中的其中一部分
   6. 評量任務也希望後台有開關可以控制是否顯示，不顯示的情境可能是學校的作答狀況不理想，完成率低
   7. 希望呈現的重點元素：正確率、作答時間、PR值（排名、落點分析、相對數值）
   8. 素養能力指標長條圖＆難易度題目的正確率，比較需要題數的累積，因此可以不需要顯示在評量任務
2. 其他必要調整的問題（以重要性排序）：&#x20;
   1. 少了答題時間的數據（可以先單純呈現，不需要和全班、全年級對照）
   2. 遊戲元素較少，希望新增遊戲角色的頭貼
   3. 少了每個月完成率、正確率的折線圖（個人的趨勢可能比較不會那麼穩定成長，2S 內部再討論之後下次是否要新增）
   4. 缺少教材名稱（期中或上下學期換教材的話，需要印兩份學期成果表，導致老師、學生無法分辨）
   5. 雷達圖缺少上、下學期的呈現（這次只會先印上學期數據，因此可以下一次進行優化）&#x20;
3. 學期成果表若沒有評量任務，第二頁要顯示的內容為何？&#x20;
   1. 期待：顯示舊版的各領域分數
   2. 可能作法：評量任務＆各領域分數皆有後台開關可以控制，但擇一（因為學期成果表最多兩面，相當於一張A4）

<summary>12/06 會議記錄</summary>

參與者：峻賓、琬羚

1. 道明的狀況較特殊，第一次評量的母體為自己的學校，僅有一個年級；第二次評量的母體才是全國私校
2. 道明其實是想要看到 PR 值的學校，只是這學習的特殊狀況會導致 113-1 學期的兩次評量任務間沒有什麼比較的價值（因母體不同），但運營或許先實際看一下成果表的內容，才評估是否要向道明解釋這個狀況
3. 這版的等級先維持不受後台「控制 PR 顯示的開關」影響，皆會固定顯示。等觀察這次學習成果表的狀況後，下學期再決定是否進行規則的連動
4. 運營希望各評量任務狀況區塊，用戶第一時間看到的重點會是「等級」（相對概念），而不是正確率，因此希望透過其他方式去降低正確率的比重（重點其實是淡化正確率是絕對數字，而造成的衝擊。引導用戶第一眼先看到等級這個相對概念）
5. 輸出成果表時，必須確保該評量任務的結束時間已到，也就是不會有同學繼續作答。這樣才能夠避免同一位學生在上、下學習的成果表中，同一次評量任務即使正確率相同，但對應的 PR & 等級卻改變了（不直接從後台擋掉，避免選到尚未結束的評量任務，是因為內部需要提早測試，而測試時的第二次評量任務處於尚未結束的狀態）
